# Comments for juheeoh.com

This repository stores public comments and reactions for blog posts on [juheeoh.com](https://juheeoh.com).

Comments are powered by [giscus](https://giscus.app) and stored in [GitHub Discussions](https://github.com/juheeeehuj/blog-comments/discussions). Each blog post has its own discussion in the Announcements category.

The website source code is maintained separately. This repository contains only the public comment space.
